UniTime-gemma4 env 单独建, transformers 5.x 才有 Gemma4ForConditionalGeneration.

## 数据集

GTEA: 28 个 egocentric cooking videos, 11 action classes, split1 (S2/S3/S4 train=21 videos, S1 test=7 videos)
- 视频: `/nfs/hpc/dgx2-4/data/TAS_videos/gtea/*.mp4`
- 标注 v1 (单词): `data/gtea/annot/{train,test}.json` — 从学长的 `gtea_csv_to_json.py` 生成
- 标注 v2 (描述性): `data/gtea/annot/{train,test}_v2.json` — `data/gtea/generate_v2_annot.py` 生成, 把 "take" 映射成 "The person takes an object or ingredient from the workspace."

每个 json entry 是一个 (video, action_class) pair, mode=mr_seg, 包含该 action 在视频中所有出现的 time windows.
train.json: 162 entries (21 videos × ~8 classes/video), test.json: 54 entries (7 videos × ~8 classes/video).

## Features

UniTime 的 Qwen2-VL 和 Gemma3 训练需要先离线提取 visual features (vision encoder 跑一次, 训练时不重复跑).
Gemma4 走 pixel_values path, 每步重跑 vision encoder, 不需要提取.

| 模型 | Features 路径 | 提取方式 | token/frame |
|------|---------------|----------|-------------|
| Qwen2-VL-7B | /nfs/hpc/dgx2-4/tmp/2026/4/6/feature/Qwen2-VL-7B-Instruct/gtea | 学长用 feature_offline.py | 动态 (8×8=64 merge后) |
| Qwen2-VL-2B | /nfs/hpc/dgx2-4/tmp/2026/4/6/feature/Qwen2-VL-2B-Instruct/gtea | feature_offline.py | 同上 |
| Gemma3 4B | /nfs/hpc/share/zhanhaoc/MODLE/Gemma3-4B-it/features/gtea | extract_gemma_features.py | 256/frame, dim=2560 |
| Gemma3 12B | /nfs/hpc/share/zhanhaoc/MODLE/Gemma3-12B-it/features/gtea | extract_gemma_features.py | 256/frame, dim=3840 |
| Gemma4 E4B | 无 (pixel_values path) | — | 280/frame (model 自己算) |

## 代码改动 (相对 upstream Lzq5/UniTime)

Qwen2-VL 部分无改动, 用原版. 以下是新增文件:

**Gemma3 port (Apr 8-10):**
- `models/gemma3_vl.py` — Gemma3VLMRForConditionalGeneration, 继承 Gemma3ForConditionalGeneration, 加 feature_inputs masked_scatter path
- `collators/gemma3_vl.py` — Gemma3DataCollator, 支持 timestamp 和 binary 两种 target mode
- `collators/gemma_vision_process.py` — 加载 .pt cached features
- `loaders/gemma3_vl.py` — Gemma3ModelLoader
- `extract_gemma_features.py` — SigLIP-2 feature extraction
- `eval_gemma3.py` — teacher-forced argmax eval

**Gemma4 port (Apr 9-10):**
- `models/gemma4_vl.py` — Gemma4VLMRForConditionalGeneration, 支持 feature_inputs + pixel_values 双路
- `collators/gemma4_vl.py` — pixel_values path, 每步 load PIL images
- `loaders/gemma4_vl.py` — Gemma4ModelLoader
- `extract_gemma4_features.py` — video processor path (70 tokens/frame)
- `eval_gemma4.py` — pixel_values eval, 含 nccl init workaround

**共用:**
- `supported_models.py` — 注册 gemma3-4b-it, gemma3-12b-it, gemma4-e4b-it + MODULE_KEYWORDS
- `collators/__init__.py`, `loaders/__init__.py` — import guards (gemma4 需 tf5.x)
- `datasets_mr.py` — 加 model_family_id 分发, gemma3 走 construct_messages_gemma3()
- `utils.py` — _get_train_sampler 加 dataset 参数 (transformers 5.x 兼容)
- `eval_tas_metrics.py` — ASFormer-standard dense TAS metrics (F1@{10,25,50}, Edit, Acc)
- `eval_zeroshot_qwen.py` — zero-shot UniTime LoRA on GTEA
- `feature_offline.py` — 加 gtea dataset 识别

## 训练脚本

| 脚本 | 模型 | 方法 | 关键参数 |
|------|------|------|----------|
| scripts/train.sh | Qwen2-VL-7B | LoRA, timestamp | MODEL_MAX_LEN=24576, 1 epoch |
| scripts/train_qwen2vl_2b.sh | Qwen2-VL-2B | LoRA, timestamp | MODEL_MAX_LEN=24576, 2 epochs |
| scripts/train_gemma3.sh | Gemma3 4B | LoRA, timestamp | MODEL_MAX_LEN=16384, 2 epochs |
| scripts/train_gemma3_v2.sh | Gemma3 4B | LoRA, binary+desc | UNITIME_TARGET_MODE=binary, 2 epochs |
| scripts/train_gemma3_12b.sh | Gemma3 12B | LoRA, timestamp | MODEL_MAX_LEN=16384, 2 epochs |
| scripts/train_gemma4.sh | Gemma4 E4B | LoRA, timestamp, pixel_values | MODEL_MAX_LEN=16384, 2 epochs |

所有训练: 单 GPU H100 80GB, deepspeed zero2, bf16, LoRA r=8 α=8, lr=2e-4, cosine, batch=1.
